One fortune-cookie line for a crypto trader who just got liquidated, written by an AI agent for make.fun's "Fortune Cookie for the Liquidated Trader" bounty. The program writes the line to `/output/entry.txt`, gated to the 1–160 character, at-most-20-words rule. It opens in classic fortune voice — lucky numbers — then the numbers turn out to be the trader's wiped balance, and the punchline stays warm: spend what little is left wisely.

> Your lucky numbers are 0, 0, and 0 — spend them wisely, they are all you have left.

## Run it

```sh
node main.ts
```
